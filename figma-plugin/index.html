AegisUI Token Sync

A Figma plugin that turns an AegisUI token file into Local Variables (Light and Dark), text and effect styles, token-bound components and a style guide page. It runs locally, makes no network requests and is safe to re-run.

Status: the plugin is tested end to end against a strict Figma API mock (npm run test:plugin). It has not yet been checked in the Figma desktop app, so treat the first real import as a trial run.

Install (development)

  1. Download or clone this repository so the figma-plugin/ folder is on your computer.
  2. In the Figma desktop app, choose Plugins → Development → Import plugin from manifest…
  3. Select figma-plugin/manifest.json.
  4. Run Plugins → Development → AegisUI Token Sync.

What to import

The plugin accepts the canonical AegisUI token format ("aegis": { "format": "aegis-tokens", "version": "1.x" }), specified in presets/schema/aegis-tokens.schema.json. Any of these works:

  • Studio: Studio → Code & Token Export → aegis-tokens.json. It's also included in the Studio's .zip bundle as tokens/aegis-tokens.json.
  • Preset Vault: Preset Vault → Copy JSON or Download JSON, or any presets/tokens/<id>.json.
  • Bundled presets: the plugin's Presets tab ships all 12 presets.

Studio's older exports, variables.css and the W3C DTCG tokens.json, are unchanged and are not plugin input.

Check a token file before importing

This runs the plugin's own validation (the same checks, ported to shared/aegis-contract.js and kept in sync by the test suite) plus the JSON schema when this page is served over HTTP.

What the plugin generates

Figma output by collection
OutputContents
PrimitivesColor ramps as variables, hidden from pickers
Semantic (Light, Dark)bg, fg, border, brand, accent, status and data roles aliased to primitives
Dimensions, Typography, MotionSpacing, radius, border widths, sizes, font families and weights, durations, easings
ComponentsButton, input, card, badge, table, tabs, modal, tooltip, nav and more, aliased to the above
Styles16 text styles and light/dark elevation effect styles
Style guide pageFoundations in both modes, token-bound component sets and component-token tables

Every variable carries WEB code syntax (var(--aegis-…)). Re-running updates collections, variables and styles by name, so existing bindings survive. Full details are in figma-plugin/README.md.

Known limitations

  • Fonts that aren't installed in Figma are replaced with the closest weight of Inter, and the plugin lists each substitution. Studio exports name the first concrete family in a font stack (for system stacks that's often Segoe UI), which usually means Inter in Figma.
  • Studio has no separate accent hue, so in Studio exports the canonical accent roles alias the info ramp.
  • On Figma plans that limit modes per collection, Dark goes into a separate Semantic (Dark) collection.
