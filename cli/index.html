Command-line tool

aegis-init

One command scaffolds an AegisUI preset into your project. Your CSS and your AI coding assistant get the same design tokens.

Full CLI reference (Markdown) Browse the 12 presets

Quick start

You need Node 18 or later. There are no dependencies, no build step and no network calls: the CLI only reads this repository's presets/ folder and writes into --out.

node cli/aegis-init.js --list                         # 12 presets + aliases
node cli/aegis-init.js --preset=gov --out=./my-app    # scaffold tokens + AI rule files
node --test cli/test/*.test.js                        # CLI tests

Then load the tokens in your app:

<html data-aegis-theme="gov-accessible" data-aegis-mode="light">
  <head><link rel="stylesheet" href="variables.css"></head>

What it writes

variables.css

Every token as a --aegis-* custom property, with light, dark and auto blocks.

tokens.json

A byte-identical copy of the preset's token document. The Figma plugin imports it as is.

CLAUDE.md

Rules for Claude Code: the semantic color table, text styles, scales and component recipes.

.cursorrules

The same rules in condensed form for Cursor.

presets/tokens/<id>.json + presets/css/<id>.css ──► cli/aegis-init.js ──► variables.css · tokens.json · CLAUDE.md · .cursorrules

Options

OptionMeaning
--preset=<id|alias>Required. A preset id or alias, such as fintech or gov.
--out=<dir>Required. Output folder inside the current working directory. Created if missing.
--mode=light|dark|autoMode used in the generated rule files. variables.css always has every mode.
--force, -fReplace existing output files.
--dry-runValidate and print what would be written, without writing.
--no-fontsDrop the Google Fonts @import, for self-hosted fonts or strict CSPs.
--jsonMachine-readable output.
--list, -lList presets with their aliases.

Safety

  • No overwrites by default. If any target file exists, nothing is written and the CLI exits with code 2. Pass --force to replace them.
  • Atomic writes. Each file is written to a temp file and renamed into place, then read back and validated.
  • Path guards. --out is refused if it contains .., leaves the working directory or goes through a symlink.
  • Validation first. The preset is checked against the token schema before anything is written.

The generated CLAUDE.md reports the preset's automated contrast checks on token pairs. That is not an accessibility audit or certification.
