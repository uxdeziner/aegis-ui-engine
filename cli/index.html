Command line

aegis-init

Scaffold any of the 12 AegisUI presets into a project, so your code and your AI coding assistant work from the same tokens.

  • Node 18 or later
  • Zero dependencies
  • No network calls
  • Never overwrites without --force

    Build your command

    Relative to the folder you run it from. It's created if missing.

    Use cli/aegis-init.js from the AegisUI repo root, or a path such as ../aegis-ui-engine/cli/aegis-init.js from your own project.

    Mode for the AI rule files

    variables.css always contains every mode. This picks the mode shown in CLAUDE.md and .cursorrules.

    Command

    What you'll see

    Byte counts come from the CLI's own dry run for this preset, mode and fonts setting.

    Then in your app

    For the .ae-* component classes, also copy presets/aegis-components.css. The CLI writes token files only.

    FileBytesSourceContents

    Exit codes

    0
    Success
    1
    Usage error: unknown option or preset, or a bad path
    2
    Output files already exist. Nothing was written; re-run with --force
    3
    Preset data invalid or out of sync, or an IO error

    Safety

    • Checks all four files first. If any exists, it writes nothing unless you pass --force.
    • Writes each file to a temp file, then renames it into place, then reads it back and validates it.
    • Refuses an output folder with .., an absolute path, a symlinked folder, or one outside the current folder.
    • Validates the preset against the token schema before writing anything.

    This page only builds the command. It never runs anything or writes files. Full reference: cli/README.md.
